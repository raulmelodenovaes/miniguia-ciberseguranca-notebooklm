# 🔐 Miniguia de Cibersegurança com NotebookLM

## 📚 Sobre o Projeto

Este projeto foi desenvolvido como desafio da DIO utilizando o NotebookLM como ferramenta de aprendizagem ativa em Cibersegurança.

O objetivo foi estudar tendências, ameaças e estratégias modernas de segurança digital utilizando Inteligência Artificial para organizar informações, gerar resumos e aprofundar conhecimentos técnicos.

# 🛡️ Principais Tendências de Cibersegurança

## Inteligência Artificial

A IA está sendo utilizada tanto para defesa quanto para ataques cibernéticos. Empresas utilizam IA para detecção de ameaças, enquanto criminosos usam deepfakes, phishing automatizado e malwares inteligentes.

## Zero Trust

O modelo Zero Trust trabalha com verificação contínua e acesso mínimo necessário, reduzindo movimentações não autorizadas dentro das redes.

## IoT e Redes 5G

O crescimento de dispositivos IoT aumenta a superfície de ataque e gera novos riscos para empresas e infraestruturas críticas.

## Security by Design

A segurança deve ser implementada desde o início do desenvolvimento de sistemas e aplicações.

---

# 🔐 Pilares da Segurança da Informação

## Confidencialidade
Garantir que apenas pessoas autorizadas tenham acesso às informações.

## Integridade
Garantir que os dados não sejam alterados indevidamente.

## Disponibilidade
Garantir que sistemas e dados estejam disponíveis quando necessários.
